# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, and everyone who takes part in its issues, pull requests and discussions is expected to follow it.

In short, be considerate and constructive, assume good faith, and keep criticism to the work rather than the person. Harassment, personal attacks and discriminatory language are not acceptable in any form.

## Reporting

If you experience or witness behaviour that breaks the code of conduct, please report it privately to the maintainer, [@ChristopherALewis](https://github.com/ChristopherALewis), through the contact details on that GitHub profile, rather than in a public issue. Reports are handled in confidence, and the maintainer will respond as set out in the enforcement guidelines of the Contributor Covenant.
